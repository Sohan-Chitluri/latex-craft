\chapter*{Executive Summary}
\addcontentsline{toc}{chapter}{Executive Summary}
This project details the end-to-end design, implementation, and empirical testing of an autonomous mobile robotic platform. The system integrates real-time LiDAR SLAM, deep learning vision models for obstacle avoidance, and decentralized motor control on edge hardware. Experimental trials confirmed autonomous waypoint navigation with centimeter-level precision.

\chapter{Introduction and Objectives}
\section{Problem Statement}
Unstructured indoor environments present significant localization challenges for low-cost mobile robots.

\section{Project Deliverables}
\begin{itemize}
    \item Custom PCB motor driver board with CAN-bus telemetry.
    \item Real-time embedded SLAM module operating at 30Hz.
    \item Comprehensive safety subsystem with redundant emergency braking.
\end{itemize}

\chapter{System Design and Architecture}
\section{Hardware Subsystem}
The vehicle chassis utilizes differential four-wheel drive with brushless DC motors and optical quadrature encoders.

\section{Software Pipeline}
Sensor fusion merges 2D LiDAR scans with IMU dead reckoning through an Extended Kalman Filter (EKF).
